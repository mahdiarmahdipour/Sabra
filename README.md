# وب‌سایت نمایش آیینی صبرا

نسخهٔ رسمی وب‌سایت فارسی نمایش «صبرا» با طراحی واکنش‌گرا، تم شب و روز، اسلایدر تصاویر، پخش تریلر و فرم رزرو بلیط.

## بخش‌ها

- صفحه خانه
- نمایش صبرا
- تهیه بلیط
- نذر فرهنگی
- اخبار پیرامونی
- درباره ما

فرم تهیه بلیط در نسخهٔ فعلی نمایشی است و پس از ثبت، کد پیگیری آزمایشی ارائه می‌کند؛ اتصال به درگاه و سامانهٔ ذخیره‌سازی در مرحلهٔ بعد انجام می‌شود.

تمام تصاویر، ویدیو و فونت‌های این مخزن متعلق به صاحبان اثر هستند.
